About

Software that survives a restaurant rush — not just a demo.

I’m on the Marn team at Jahez Group in Riyadh, building the point-of-sale apps that run restaurants across Saudi Arabia. On a busy floor the internet drops mid-service — the order still has to reach the kitchen, the receipt still has to print, and every device has to agree on the bill. Reliability isn’t a feature there; it’s the baseline.

Before Jahez I shipped the capital’s parking apps for the Riyadh Municipality — map-heavy, Arabic-first products where a stale timer means a real fine — and before that, health-tech, logistics and messaging apps in Cairo. That road shaped how I design: local database as source of truth, a sync queue for the cloud, repositories that hide I/O, and ViewModels that never touch the network.

I care about maintainability over cleverness — MVVM with Combine or RxSwift, typed failures, SPM modules, tests around the money-moving code, and legacy migrations that land as small, always-buildable steps while releases keep shipping.

Engineering philosophy

Rules I actually follow in the codebases above.

Local first, then sync

The device database is the source of truth. Every sale lands in Core Data inside one transaction, then a background queue replays it to the cloud when connectivity returns.

Marn POS · Marn KDS

ViewModels never touch I/O

Repositories own URLSession, Core Data and SignalR. ViewModels orchestrate state from publishers and typed results, so screens stay testable and swappable.

Marn POS · EMLE · every codebase since

Failures are values

Network calls return Result<T, AppError> through a single safe wrapper, so error handling is uniform and never an afterthought.

Marn POS · EMLE · Ayamedica

Test the money paths

Pricing, discounts, VAT rounding and sync ordering get unit tests before UI polish — a receipt is a fiscal document, not a label.

Marn POS

Migrate in small steps

Legacy migrations ship as small, always-buildable steps — MVC becomes MVVM screen by screen while releases keep going out on schedule.

Riyadh Parking · Mawqfi · Ayamedica

Hardware fails politely

Printers, scanners and NFC fail politely. Retry quietly, queue the job, never block the counter.

Marn POS · Swipy
